Wayfarer Wanderer brings IntelliJ IDEA's workflow (keymap, navigation, run configurations, tests, and debugging) to an open language backend. Free and open source.

Mixed Java and Kotlin projects

Java and Kotlin files are handled by their own language servers: Eclipse JDT LS for Java and kotlin-lsp for Kotlin. In Maven projects, Wayfarer compiles Kotlin sources using the project's wrapper so Java code can resolve Kotlin declarations, letting you jump between languages with Ctrl+B.

Safe opening with Workspace Trust

When you open an unfamiliar repository, you can browse and edit files immediately without running anything from the project. Wayfarer holds off on running Maven or Gradle wrappers, build daemons, and language-server imports until you explicitly trust the folder. Any unsaved edits stay intact when the import runs, even if it fails.

  1. OpenFiles open right away with syntax highlighting and editing
  2. TrustNothing in the repository runs until you click Trust Workspace
  3. ImportYour Maven or Gradle wrapper imports modules, packages, and source/test roots
  4. WorkBuild, test, run, and debug as usual

JUnit test runner

JUnit tests run through your project's Maven or Gradle build. Each run writes to a fresh report directory so stale results from an earlier pass can't mask a failed build.

Example of two runs

run-41/ · 12 passed

New project wizard

Create Java projects using IntelliJ, Maven, or Gradle, or Kotlin projects using Maven or Gradle. Pick a detected JDK, add one from disk, or choose Download JDK…. New projects are staged first and moved into place only after every file is generated.

Debugging with inline values

Set a breakpoint with Ctrl+F8, start a debug session with Shift+F9, and step through code using F8 and F7. The Debug tab lists the call stack and locals while the editor shows values inline.

Themes and accessibility

Three themes in light and dark variants, including a WCAG AAA High Contrast theme. Optional sound cues announce what the caret lands on, and UI states never rely on colour alone.

Built on standard tools

Wayfarer focuses on the desktop IDE shell and delegates language intelligence and builds to standard tools.

Wayfarer Wanderer

Window chrome, actions, keymaps, run configurations, test runner, and debugger UI. Built with .NET and Avalonia on top of the editor, terminal, Git, and DAP libraries from Passenger.

Java

Eclipse JDT LS for completion, navigation, hover docs, rename, and inlay hints.

Kotlin

JetBrains kotlin-lsp standalone language server.

Build system

Maven and Gradle invoked through your repository's own wrapper, matching what your team and CI run.
